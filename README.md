# editor-settings

VSCode 向けの Emacs 風キーバインド実装プロジェクト。

## セットアップ

`keybindings.json` を VSCode のキーバインディング設定にコピーしてください。

### VSCode での設定方法

1. `Ctrl+K Ctrl+S` でキーボードショートカットを開く
2. 右上の "キーバインディングを JSON で編集" をクリック
3. [`vscode/keybindings.json`](./vscode/keybindings.json) の内容をコピーして追加

または

1. `~/.config/Code/User/keybindings.json` (Linux/Mac) または `%APPDATA%\Code\User\keybindings.json` (Windows) に直接コピー
